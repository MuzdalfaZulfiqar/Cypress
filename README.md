# Cypress — AST FYP Testing

This repository contains automated end-to-end and visual regression tests developed as part of the Application Software Testing (AST) Final Year Project (FYP).

## Testing

- **End-to-End Testing** — Validate application workflows using Cypress.
- **Visual Regression Testing** — Capture and compare screenshots to identify UI changes.
- **Test Fixtures** — Store reusable test data and supporting files.
- **Test Support** — Maintain reusable commands and testing utilities.

## Tech Stack

- Cypress
- JavaScript
- Node.js
